# 기기별 화면 크기와 Studio 미리보기

## 조사 결과와 구현 기준

기기 해상도, Minecraft의 GUI 배율, JSON UI 작업 좌표, 브라우저 확대는 서로 다른 값입니다. `480 × 270`은 이 도구의 기존 시험 좌표이며 모든 PC의 기본값이 아닙니다.

공식 [Bedrock samples v1.26.50.4의 설정 정의](https://github.com/Mojang/bedrock-samples/blob/46ba6ea985fb5a92d79a9419198f10dda14c199d/resource_pack/ui/settings_sections/general_section.json)는 GUI 배율 값·단계·활성 여부를 엔진 바인딩에서 받습니다. 이 JSON에는 출력 해상도로 배율을 결정하는 보편적인 공식이 없습니다. Pocket/Classic 선택도 별도 설정이며 콘솔 분기가 존재합니다. 그래서 Studio는 기기 이름만으로 GUI 배율이나 UI 분기를 단정하지 않습니다.

**해상도 근거와 작업 좌표 근거를 구분합니다.** 제조사 사양은 패널의 기본 해상도이며 게임의 실제 출력·내부 렌더 크기는 달라질 수 있습니다. 모든 초기 작업 좌표는 편집 가능한 시험값입니다. 현재 게임에서 측정한 root 크기를 알고 있으면 직접 입력합니다. 정수로 반올림한 작업 크기는 비율에 작은 오차가 생길 수 있습니다.

콘솔의 각 변 5% 여백은 위 Microsoft 문서의 HDTV 내부 90% 영역을 참고한 보수적인 시험값입니다. 문서는 이전 TV 환경을 다루며, 현재 Xbox 전체의 의무 규칙으로 해석하지 않습니다. 실제 게임의 화면 안전 영역 설정으로 조정합니다.

모바일 노치 여백을 기기 이름으로 하드코딩하지 않습니다. [Android 공식 문서](https://developer.android.com/develop/ui/views/layout/display-cutout)는 런타임 cutout과 window insets로 가리는 영역을 처리하도록 설명합니다. Studio의 모바일 초기 여백 0은 측정하지 않았음을 뜻하며, 노치가 없다는 판정이 아닙니다. 전체 화면 캡처와 게임 설정을 보고 각 변의 여백을 입력합니다.

## 사용법

1. 상단 **기기**에서 PC·태블릿·콘솔·모바일 프리셋을 선택합니다.
2. **크기 설정**에서 출력 해상도와 작업 크기를 따로 입력합니다. 전체 화면 캡처의 이미지 크기도 읽을 수 있습니다. 캡처는 RP에 추가하거나 서버에 업로드하지 않습니다.
3. **출력 비율 맞추기**는 작업 높이를 유지하며 너비를 계산합니다. **UI 크기 비교**는 선택한 작업 높이에 맞춰 같은 비율의 크기를 계산합니다. Minecraft의 GUI 배율 설정값을 자동 변환하는 기능은 아닙니다.
4. 안전 여백은 왼쪽·위·오른쪽·아래에 각각 0~25%를 입력합니다. **안전 영역** 버튼으로 표시를 켜고 끕니다.
5. **기기별 비교**는 같은 원본을 PC·iPad·콘솔·iPhone 시험 좌표로 다시 렌더링합니다. 원본·선택·실행 취소·현재 작업 크기는 유지합니다. 카드의 **이 크기로 편집**으로 전환합니다.

크기 설정은 `workspace/studio-runtime/last-project.json`에 저장되고 다시 실행할 때 복원됩니다. Codex 선택 문맥에도 기기 해상도·안전 여백·시험값 여부를 전달합니다. 측정하지 않은 GUI 배율이나 기기 입력을 검증했다고 주장하지 않습니다.

## 추가 편의 기능

- **선택 확대 / F:** 선택 요소가 작업 화면에 들어오도록 확대하고 가운데로 이동합니다.
- **Space+드래그 / 휠 버튼 드래그:** 확대된 화면을 이동합니다. 요소 위치는 바꾸지 않습니다.
- **집중 모드:** 양쪽 패널을 접어 작업 공간을 넓힙니다.
- **PNG 저장:** 안내선과 선택 테두리를 제외한 미리보기를 기본 2배 해상도로 저장합니다. 대체 글꼴을 사용하면 게임과 다른 글자 폭이 유지됩니다.
- **정렬·간격 → 크기 같게:** 선택 요소의 최대 너비·높이를 적용합니다. 동적 값과 IR 소유권 보호는 유지합니다.
- **배치 검사:** 현재 작업 영역 밖의 요소와 설정한 안전 여백에 걸친 요소를 보여 줍니다. 전체 배경과 숨긴 요소는 제외합니다. 선언 영역 검사이며 실제 글자 픽셀·터치 영역·컨트롤러 포커스 검증은 아닙니다.

## 검증 목록

기기별 비율·안전 영역·직접 입력·방향 교환·캡처 크기 읽기·PNG 저장·비교 후 상태 보존을 확인합니다. 정렬 창과 크기 통일, 선택 확대·화면 이동·집중 모드, 390/768/1024/1366/1600/1920px 편집기 배치와 DPR 2를 실제 브라우저에서 확인합니다. 원본 저장 테스트는 별도 RP 사본에서 수행합니다. Minecraft 기기별 런타임 확인은 별도 단계입니다.
