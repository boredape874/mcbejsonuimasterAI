# Registered community UI packs, libraries and tools

Reviewed 2026-10-03. Every source below is commit-pinned in `config/design-research-lock.json` and summarised in `data/design-sources.json`; its analysis cards are read with `node tools/design-library.mjs patterns --source <id>` and never enter a style context automatically (`contextPolicy: explicit-source-only`). These packs are pattern evidence: a name they use is cited only after `node tools/vanilla-name-check.mjs <name>` finds it in the pinned vanilla files, and nothing here is runtime-verified on the target client.

GPL-3.0 sources are analysis-only: describe the structure, never copy JSON, texture, variable or marker strings into a deliverable. MIT sources may be adapted with their copyright notice. NOASSERTION sources are cited for structure only.

## Patterns worth carrying over (structure only)

- Title-prefix routing with string subtraction is shared by three independent packs (`kaweduh`, `avatar`, `starlib`) and by the Bedrock Wiki page on modifying server forms; keep both vanilla form routes (`long_form`, `custom_form`) alive and derive visibility from `#title_text` or `#form_button_text`, never from a renamed vanilla control.
- Collection-driven browsers either run the vanilla `form_buttons` factory (collect-everything) or pin fixed `collection_index` values per role (avatar). The fixed-index contract moves ordering into the script that builds the form; document the index map next to the BP code.
- HUD data channels re-target `hud_title_text_factory` (avatar) or parse `#hud_title_text_string` (repository `references/local-examples/rpg-hud`); both keep the vanilla factory name and replace only `control_ids`.
- Nine-slice sidecar JSON appears in every pack as `nineslice_size` (array or integer), `base_size` equal to the PNG size and optional `tiled`; `tools/final-rp-render.mjs` must accept all three shapes.
