# V2 Casino Reels

Five by three reel grid with a separate betting panel.

- Design family: `casino_reel_panel`
- Protocol token: `v2:casino`
- Profiles: `pc_1920x1080_gui3`, `touch_1280x720_gui2`
- Assets: generated first-party PNG files with same-stem nine-slice JSON
- Validation status: static structure only; Bedrock runtime and content-log checks remain pending

Install both `RP` and `BP` in one test world. The BP opens or updates the example after initial player spawn.
