# MCBE JSON UI Design System V2 Examples

Seven independent RP/BP examples demonstrate measured typography, button states, repeated layouts, HUD markers, book pages, a five-by-three casino reel grid, and PC/touch-safe sizing.

Regenerate deterministic first-party assets and scaffold files with:

```powershell
node examples/v2/_scripts/generate.mjs
```

Every example records static validation separately from pending Bedrock runtime evidence.
